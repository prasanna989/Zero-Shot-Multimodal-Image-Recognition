\# Zero-Shot Multimodal Image Recognition using ESRGAN and CLIP



\## Overview

This project implements a Zero-Shot Multimodal Image Recognition system by combining ESRGAN (Enhanced Super-Resolution Generative Adversarial Network) and CLIP (Contrastive Language-Image Pre-training). The system enhances low-resolution images and classifies unseen objects without requiring task-specific training.



\## Features

\- Zero-shot image classification

\- Image enhancement using ESRGAN

\- Vision-language understanding using CLIP

\- Recognition of previously unseen object categories

\- Improved performance on low-resolution images

\- Efficient multimodal learning approach



\## Technologies Used

\- Python

\- PyTorch

\- OpenCV

\- NumPy

\- ESRGAN

\- CLIP

\- Vision-Language Models (VLMs)



\## Project Workflow

1\. Input image is provided to the system.

2\. ESRGAN enhances image quality and resolution.

3\. CLIP extracts visual and textual features.

4\. Similarity matching is performed between image and text prompts.

5\. The most relevant class is predicted as output.
